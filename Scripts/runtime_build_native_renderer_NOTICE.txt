This recipe builds unchanged public source into a separate ARM64 provider. It
never modifies Vendor, the active runtime generation, or the default settings.
A built/tested candidate is not whole-application distribution approval.

The provider's share/ready/sources retains all six complete input archives.
share/ready/notices retains upstream documents; source archives also retain
individual source headers. share/ready/recipes retains each actual orchestration
snapshot and the full GPL-3.0-only license. share/ready/receipts retains exact
commands/log hashes, CMake/Meson metadata, compile database, final link map,
normalization and signing commands. Dynamic dependency identities are parsed
from actual Mach-O load commands, not inferred from filenames or SONAMEs.

Only four source-built dylibs and their relative aliases form the candidate
runtime closure: Kosmic, zstd, SPIRV-Tools and Vulkan Loader. Other dependencies
are macOS system libraries/frameworks. The final ICD link map has364 object
entries and contains no Homebrew archive/object or MesaCLC/LLVM/clang-cpp/
LLVMSPIRV compiler object. Those compilers are host tools, not runtime inputs.
Mesa's libclc dependency is not enabled for this Kosmic-only configuration;
its generated kernel library comes from Mesa CL/libcl/poly sources.

macOS27 is the actual minimum encoded in all four ARM64 dylibs. No macOS14
compatibility, DXVK/VKD3D capability, complete Vulkan conformance, or game
compatibility is claimed by these build/probe receipts. Apple evaluation files
are entirely excluded. The runtime source still uses platform Metal APIs.
